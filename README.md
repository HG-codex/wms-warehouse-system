# WMS 仓库管理系统

这是一个用于展示物流 / 仓储管理能力的前端页面，适合用于个人作品和网申展示。

## 运行方式

1. 在浏览器中直接打开 `index.html`
2. 或者在项目目录执行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 功能概览

- 仓库总览：订单量、效率、缺货预警、出库率
- 订单管理：订单状态展示与处理入口
- 库存管理：SKU、库位、库存可用量、锁定库存
- 拣货任务：任务号、拣货员、数量与状态
- 出库发货：物流单号、承运商、发货状态
- 报表分析：履约率与异常原因分布

## 适合岗位

- 仓储运营
- 物流专员
- 供应链管理
- 电商仓库管理
- WMS / ERP 相关岗位

## 说明

该项目使用模拟数据，适合在简历和作品集里展示业务能力，后期可以继续扩展为真实前后端系统。
